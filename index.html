Execution Notes

Learning Windows

Platforms need 3-5 days to optimize algorithms. Don't make changes too early.

Creative Fatigue

Swap assets after 14 days to maintain performance. Gen Z audiences scroll fast.

Budget Pacing

30% in testing phase prevents overspending on untested creative.

Success Checkpoint

By Week 4, you should see clear winners. If CTR is below 1.2%, revisit messaging. If above 2%, scale aggressively.
